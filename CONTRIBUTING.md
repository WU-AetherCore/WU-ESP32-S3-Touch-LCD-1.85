# Contributing

1. Build with ESP-IDF 5.5.5 and target `esp32s3`.
2. Keep UI text inside the generated CJK character set and regenerate the font.
3. Do not commit `build/`, `managed_components/`, credentials, raw SD media, or full serial logs.
4. Test the affected page and run the relevant host-side verification script.
5. Describe the board revision, firmware commit and test result in the pull request.
